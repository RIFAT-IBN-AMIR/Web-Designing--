# Web-Designing-Ⅰ

## Webデザイン学習の始まり（2026年4月25日）

本日、私は正式にWebデザインの学習を開始しました。

私の主なキャリア目標は情報セキュリティ分野にありますが、いくつかの重要な理由からWebデザインについても深く学ぶことにしました。

現在、私は大学3年生（第5学期）であり、今学期にはWebデザインがカリキュラムに含まれています。しかし、単なる学業の一環としてだけでなく、将来のための戦略的なステップとしてこの分野に取り組んでいます。

これまでにHTML、CSS、JavaScript、Pythonの基礎を学んでおり、Webデザインにもスムーズに取り組むことができます。しかし、私の目標は単にWebサイトを作ることではなく、Webアプリケーションの構造・動作・各レイヤーを0から100まで深く理解することです。

## なぜこれが自分のキャリアに重要なのか
  情報セキュリティ、特にWebセキュリティの分野では、システムがどのように構築されているかを理解することは、それを安全に保つことと同じくらい      重要です。
 Webアーキテクチャに関する深い理解がなければ、脆弱性の特定や強固な防御の構築は困難になります。

## Webデザインと開発の基礎を習得することでの目標

  1. Webアプリケーションの内部構造をより深く理解する  
  2. セキュリティ上の弱点をより効果的に特定する  
  3. 将来的により安全で強固なシステムを構築する  

## この学習を通じて、自分のスキルにさらなる強みを加え、セキュリティ志向のエンジニアとして成長していきたいと考えています。

## 共有していく内容

  私は基礎レベルから上級レベル（0から100）まで成長していく過程で、小さなWebプロジェクトを作成していきます。そして、それぞれのプロジェクト  のライブデモリンクをここに共有していきます。

  これにより、自分の成長を記録するとともに、これまでの成果を分かりやすく紹介していきます。
